#

The idea of this project came from the frustration of always having to edit a google sheet file to manage my expenses.

So I needed a place where I can easily track everything I spend my money on, in a efficient manner of course.

### ✅ Functionalities implemented so far:

-  An authentication process (login, register & reset password)

### ⏳ In progress

- Choose between multiple currencies
- Monthly and yearly P&L
- Edit expense
- Set monthly budget/urgent budget
- Add multiple income streams
- Filter expenses by category
- Add an interceptor for each API request

And for my backend service, I am using [Supabase](https://supabase.com).
